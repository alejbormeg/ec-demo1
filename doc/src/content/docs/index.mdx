## Qué hay aquí

<CardGrid stagger>
  <Card title="Cada dato, desde su maestro" icon="random">
    Las reservas viajan **CRS → Opera → front office**; los clientes, desde **Salesforce** a través
    del MDM. Ningún sistema recibe una copia de segunda mano: cada uno lee de quien manda.
  </Card>
  <Card title="Espera, no falla" icon="approve-check-circle">
    Un código sin mapear, un interlocutor que falta o un rechazo de Opera se convierten en una
    **causa** con nombre. El proceso espera; al resolverla, todos los que la esperaban siguen solos.
  </Card>
  <Card title="Dos planos, dos consolas" icon="laptop">
    El **plano de datos** (`ec1.mateu.io`) es lo que usa el negocio; el **plano de control**
    (`console.ec1.mateu.io`) es quién lo gobierna. Cada una, pintada por Vaadin y por Redwood.
  </Card>
  <Card title="Agentes configurables con herramientas" icon="rocket">
    El agente de la consola, el del plano de control, el de recepción y el de mapeado responden
    llamando a herramientas MCP; los sirve un solo `ia-agent` para todas las consolas, se configuran
    desde un catálogo, se llaman entre sí por A2A y pueden llevar guardarraíles.
  </Card>
</CardGrid>
